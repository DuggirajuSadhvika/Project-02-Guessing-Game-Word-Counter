# Project 02: Number Guessing Game & Word Counter

## About the Project

This is a beginner-friendly Python project that combines a Number Guessing Game and a Word Counter in a single menu-driven program.

## Features

### 1. Number Guessing Game
- Generates a random number between 1 and 100.
- Gives the user five attempts to guess the number.
- Provides hints such as "Too high" and "Too low".
- Allows the user to play again.
- Tracks the best score.

### 2. Word Counter
- Reads text from `sample.txt`.
- Counts the total number of words.
- Counts unique words.
- Displays the ten most common words.
- Handles missing files using exception handling.

## Technologies Used
- Python
- `random` module
- `string` module
- `collections.Counter`

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python project2.py
```

6. Choose an option from the menu:
   - `1` — Number Guessing Game
   - `2` — Word Counter
   - `3` — Exit

**Note:** Keep `sample.txt` in the same folder as `project2.py` to use the Word Counter.
